# GlowAura — Responsive Skincare Landing Page

## Project Overview

GlowAura is a fictional skincare startup offering everyday skincare essentials, including serums, moisturizers, and face cleansers.

## Target Audience

College students, young professionals, and skincare enthusiasts.

## Design Features

- Responsive desktop and mobile landing page
- Header with navigation and call-to-action
- Hero section with skincare product imagery
- Skincare categories and featured products
- Three feature cards
- Brand story and promotional banner
- Customer testimonials
- Newsletter subscription section
- Footer with useful links and social media icons

## Design Tools

- Figma
- Auto Layout
- Reusable Components
- Shared Color and Typography Styles
- Responsive Design

## Design System

- Blush Pink: #F4DDE1
- Warm Cream: #FFF9F4
- Muted Rose: #C77D87
- Dark Brown: #382B2B
- Heading Font: Poppins
- Body Font: Inter
